PerfLog Viewer

Performance log analyzer for !!PerfLog (WoW 1.12)

Drop one or more log files here

Logs are written to <WoW folder>\CustomData\PerfLog_<Character>_<Realm>_<date>_<client>.log — one file per client session, you can drop several at once.

Without nampower: WTF\Account\<ACCOUNT>\SavedVariables\!!PerfLog.lua (after a logout or /reload).
Everything stays in your browser: nothing is uploaded anywhere.

Tip: drag across a chart to zoom into a time range.

Automatic diagnosis

    Timeline

    in combat hitch marker (zone, loading screen, /perflog mark)

    Cost per addon

    Exclusive Lua CPU time of handlers (OnEvent / OnUpdate / OnShow / OnHide) and Lua memory allocated. “ms/s” = milliseconds used per second of play: 10 ms/s = 1% of total time.

    Most expensive handlers

    Events

    “Dispatch” = number of handler calls triggered (one event × the frames registered for it).

    Hitches

    Recorded configuration (CVars, addons, mods)
